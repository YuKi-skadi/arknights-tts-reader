# ver0.8 更新说明

## 个性化

- 侧边栏和各工作区标题图现在实际显示在 Qt 界面中。
- 左侧栏改为功能区优先的响应式布局；导航、选区和监听控制保持可见，装饰图在空间不足时自动让位。
- 选择和清除图片立即生效；复制到 data/customization，重启和移动整包后继续保留。
- 设置文件采用原子替换并保留上一份有效备份；写入错误会显示出来。

## 任务与断点

- 每个生成任务逐句保存语音清单路径、成功句数、失败句数、下一句编号和文本。
- 暂停时保存状态；正常退出先停止队列调度，等待当前语音或分析请求结束，保存断点后释放服务。
- 重启不自动生成。在“语音生成”查看未完成任务，点击“开始 / 继续队列”。
- “停止队列”保留进度，不再启动后续任务。
- “查看日志 / 重试失败”显示选中任务的逐句状态和错误，可重新排队。
- “恢复历史任务”从 data/voice_packs 的 manifest.json 重建列表；没有留下清单的旧任务无法凭空恢复，源文本缺失的任务需先恢复原文件。
- 队列损坏时尝试上一份备份，并按音频清单校正成功句数。程序同目录只允许打开一个实例，避免相互覆盖队列。
- 剧情下载队列也保存到本地，可在重启后继续待完成关卡。

## 生成正确性

- 检查文本、语速、音色、模型模式、克隆参考音频内容及情绪指令，再决定是否复用旧音频。
- 不同参数的结果分别存放，不覆盖旧的语音包；已确认兼容的旧清单可以续用。
- 旧版声音克隆记录没有音频内容校验值，首次继续时可能重新生成，以免误用已变化的音色。
- 音频完整写入后才替换正式文件，临时文件和空音频不会当作已完成片段。
- 新加入的克隆任务把参考音频复制到 data/reference_audio，移动便携目录后仍可使用。
- DeepSeek 情绪分析按批次存盘，中断后可继续剩余批次；暂停和停止在当前网络请求结束后生效。完整缓存存在时不再要求重新调用 API。

## 其他修复

- OCR 结果通过 Qt 信号回到主线程，不再由后台线程直接操作界面；旧监听会话的迟到事件会被忽略。
- 选区框可以重复打开，拖动时显示矩形范围。
- 切换语音包时停止旧监听；停止识别后不再播放尚在处理中的结果。
- 生成或下载正在运行时阻止删除资源；释放 Qwen 服务与任务启动互斥。
- Qwen 使用独立端口和进程归属，避免误关其他实例；启动输出记录在 data/logs/qwen-rocm.log 或 qwen-cuda.log。
- GUI 错误写入 data/logs/app.log；打包后的 GUI/OCR 使用内置依赖，避免混入外置 GPU Python 的不兼容包。
- 构建时隔离系统搜索路径，避免误打包 PDF/图片工具的同名 ICU 库，导致独立 EXE 无法加载 Qt。
- 原来可编辑但不会生效的数据目录改为只读；未实现的播放变速滑块禁用并说明应在生成时设置语速。

## 运行环境

本次更新不更换 runtime、runtime_cuda 和模型文件。现有 ROCm PyTorch 为 2.13.0+rocm10.0.0，CUDA PyTorch 为 2.9.1+cu128。

移动软件时请移动整个文件夹，包括 data、assets、runtime、runtime_cuda。备份 data 即可保留剧情、个性化、生成记录和语音包；模型和 GPU 环境仍在两个 runtime 目录中。

本机没有 RX 9070 XT，AMD GPU 实际推理仍需回家验证。软件逻辑的离线回归测试不能替代 AMD 显卡推理测试。
